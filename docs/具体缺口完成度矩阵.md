## 当前不可替代的外部验收项

1. 使用可发布权重和冻结真实数据集生成模型质量报告。
2. 使用真实业务样本复核多 Agent 路由和带图工具调用。
3. 提供真实 `.env.production` 后，完成后端镜像构建、完整 Compose 启动、备份恢复和发布回滚演练。
4. 在真实浏览器设备和发布环境录制训练、检测、Agent 恢复与权限拒绝流程，并据此完成答辩材料。
