# 录屏与答辩证据脚本

本文件是正式录屏和答辩 PPT 的事实来源清单，不应以模拟画面替代真实发布环境。

## 录屏顺序

1. 展示提交版本、`.env.production` 已脱敏配置、Compose 状态和 `/api/health/detail`。
2. 展示迁移版本、普通用户登录、管理员登录及一次越权拒绝。
3. 上传合规数据集，启动训练，展示任务中心在刷新或切页后恢复状态；展示训练指标、`results.csv`、导出、下载和模型登记。
4. 展示单图或批量检测、结果历史、文件下载和删除后的对象清理状态。
5. 展示 Agent 文本 SSE、会话刷新恢复、检测/统计/RAG 卡片、附件访问以及跨用户访问拒绝。
6. 展示知识文档上传、检索引用和删除清理；若供应商账号恢复，再录制带图工具调用。
7. 展示备份 manifest、恢复前确认、恢复后健康检查和回滚提交。

## 答辩 PPT 建议结构

1. 项目目标与 Release 验收范围。
2. 架构与数据流：前端、API、PostgreSQL、Redis、MinIO、训练与 Agent。
3. 训练与模型报告：仅引用 [模型报告模板](模型报告模板.md) 完成后的正式指标。
4. 检测、任务恢复和资源生命周期证据。
5. Agent、RAG、卡片持久化与权限隔离证据。
6. 生产部署、备份恢复和 CI 证据。
7. 已完成项、外部限制和下一步验收责任人。

## 禁止写入 PPT 的未验证结论

- 不能把临时两图训练的指标作为模型质量。
- 带图 Agent 已完成一次真实调用验证；正式录屏仍须使用当前账号和真实业务样本重新录制，不能把此前 `Arrearage` 失败记录当作成功证据。
- 不能把未成功构建的后端镜像或未执行的真实恢复写成已发布。
