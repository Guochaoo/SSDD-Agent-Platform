## 2. 数据集与训练过程

记录训练、验证、测试集数量及类别分布；附 `data.yaml`、参数文件、`results.csv` 和训练日志的不可变副本。训练任务必须可通过 `/api/training/status/{id}`、`/metrics/{id}` 与训练输出目录复查。

## 4. 发布与回滚

列出导出后的模型版本、MinIO/object key、文件校验和、默认模型切换记录、回滚版本及验证截图。发布前需确认模型可被检测服务加载，并完成单图、批量、视频或摄像头中与本次发布范围相符的验证。
