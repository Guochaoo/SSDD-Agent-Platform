## 发布前最小验收顺序

1. 由部署负责人从 `.env.production.example` 创建仅供本机使用的真实 `.env.production`，并替换全部示例密钥。
2. 执行 Release 手册中的迁移、Compose 启动和 `/api/health/detail` 检查；保存终端输出和截图。
3. 用至少两个普通用户和一个管理员完成登录、资源隔离、检测、历史恢复、知识库引用和删除重试的人工流程。
4. 使用最终模型权重和固定数据集完成一次真实训练/推理，写入模型报告；再据此录屏并制作 PPT。

未完成的真实环境验收项目应保留为“待补”，不能写成“已完成”。
